# Content Module

The academic content hub — **study sets**, **flashcards**, **notes** and **documents**,
plus extraction of uploaded/imported material.

- **HTTP**: `@Controller('content')` (plus `content-sources`, `documents`, `flashcards`,
  `notes`, `study-sets` controllers)
- **Key services**: `ContentSourcesService` (sources), `ContentExtractService` (extraction)
