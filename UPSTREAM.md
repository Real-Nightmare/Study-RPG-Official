# Upstream

This repository is the **Studyield** open-source project — an AI-powered learning platform — which is now being evolved toward **Study RPG** (a gamified learning experience).

## Provenance

- **Project name**: Studyield
- **Origin**: Independent open-source project (originally developed as a private codebase by the Studyield contributors; previously released under a proprietary "INFO INLET" licence).
- **Current repo**: `Real-Nightmare/Study-RPG-Official` (this repository).
- **History**: `FUTURE_GOAL.md` documents the open-source preparation and the relationship between the public and private repos.

## Provenance Requirements

1. **Preserve upstream copyright notices.** The `NOTICE` file retains attribution for the original Studyield contributors and all third-party components.
2. **Do not claim that Nightmare Studio wrote the upstream project.** Upstream Studyield was written by the Studyield contributors. Nightmare Studio is the maintainer/owner of this fork, not the author of the original upstream code.
3. **Mark modified files appropriately.** When substantially modifying upstream files, note the modification where practical (e.g. in commit messages and PR descriptions).

## Original Content Requirement (Study RPG)

All Study RPG characters, card names, lore, and artwork must be **original creations**. Do not use copyrighted characters or artwork from The Amazing Digital Circus or any other third party. "Abstraction" may remain a general conceptual inspiration only; the implementation must use original terminology, writing, and visual design.
